# Teams 初版の実環境確認（利用者）

準備と設定は [導入手順](../../docs/teams-setup.md)。本番ではなく専用テストチーム・テスト環境で行う。
このチェックはローカルのフェイクテストでは完了にならない。

1. Application ID とtenant ID、許可teamのgroup ID、2つのRSC同意を確認してパッケージを導入する。
2. テスト用ingress/workerを起動し、両方の `/healthz` を許可された経路で確認する。workerの未認証HTTP呼び出しはIAMで拒否されることを確認する。
3. 合成会話の親・返信を複数人で投稿し、スレッドで `@Arbalest` を送る。概要・根拠リンク・投稿件数・対象範囲を確認する。リンク先が同じチームの元発言であることを確認する。
4. 新規親投稿でのメンションはそのスレッドを対象にすること、メンションなしの投稿ではボットが処理しないことを確認する。
5. `findings 7` と `先週の動きを振り返って` を試し、期間内返信を含み、期間外は根拠に使わないことを確認する。
6. 根拠不明・担当未定のToDoが要確認となり、表示だけで登録や通知が発生しないことを確認する。
7. 許可外team・個人チャットでは処理しないこと、RSC未同意のテストアプリでは権限不足を返すことを確認する。
8. 一時的なGraph障害後にキューが再試行し、別チャネル/Slackへ返信しないことを確認する。アプリをテストチームから削除して停止する。

結果には確認した手順番号、日時、成功/失敗だけを残す。実会話本文・ユーザー名・トークンをリポジトリへ保存しない。
